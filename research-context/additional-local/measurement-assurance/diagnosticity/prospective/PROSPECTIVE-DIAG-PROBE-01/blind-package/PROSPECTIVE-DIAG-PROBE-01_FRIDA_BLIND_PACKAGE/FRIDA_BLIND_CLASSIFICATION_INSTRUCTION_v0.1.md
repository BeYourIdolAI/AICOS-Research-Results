# Blind classification instruction

Review CASE X and CASE Y using only the materials included with those cases.

Classify each case separately as exactly one of:

```text
DIAGNOSTIC
NON-DIAGNOSTIC
UNRESOLVED
```

For each case, report:

1. classification;
2. bounded scope of the classification;
3. decisive source evidence;
4. known uncertainties or missing evidence;
5. the minimum missing information, if any, that prevents a determinate
   classification.

Set the basis for each classification before comparing the two cases. Do not
assume that the cases should receive either the same or different results.

Do not infer facts absent from the supplied case material. Preserve
`UNRESOLVED` where the material does not support a determinate classification.

Return the two case results separately, followed by a short comparison that
describes only the observed reason for any same or different classification.
